# Experiment 2: JDBC and Networking

## Aim
To study JDBC connectivity and basic Java networking.

## 1. JDBC Program
**File:** `JDBCDemo.java`

**Description:** Connects a Java application to a MySQL database using JDBC and MySQL Connector/J.

**Output:**
JDBC Connection Successful!
Connected to MySQL Server.

## 2. Networking Program
**File:** `NetworkDemo.java`

**Description:** Uses the `java.net.InetAddress` class to display the host name and IP address.

**Output:**
Java Networking Demo
Host Name: localhost
IP Address: 127.0.0.1

## Concepts Covered
- JDBC and java.sql
- JDBC driver
- MySQL database connectivity
- java.net package
- Host name and IP address

## Language
Java
