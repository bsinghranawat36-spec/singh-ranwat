# Experiment 4: J2EE Architecture

## Aim
To understand the basic architecture of Java Enterprise Edition (J2EE).

## Program
File: J2EEDemo.java

## Description
This program demonstrates the basic layers of an enterprise application.

- Presentation Layer: Handles user interaction.
- Business Logic Layer: Processes application rules.
- Data Layer: Manages data storage and access.
- HTTP Communication: Used for communication between web clients and servers.

## How to Run

Compile the program:

```bash
javac J2EEDemo.java
```

Run the program:

```bash
java J2EEDemo
```

## Output

```text
J2EE Architecture Demo
Enterprise Application Architecture
Presentation Layer
Business Logic Layer
Data Layer
HTTP is used for web communication.
```
