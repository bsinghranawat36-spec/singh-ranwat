# Experiment 3: RMI and JNDI

## Aim
To study Remote Method Invocation and Java Naming and Directory Interface.

## 1. RMI Server
File: RMIServer.java

Creates an RMI registry on port 1099 and registers HelloService.

## 2. RMI Client
File: RMIClient.java

Looks up HelloService and calls the remote sayHello() method.

## 3. JNDI Demo
File: JNDIDemo.java

Demonstrates the use of JNDI-related Java APIs and naming service concepts.
